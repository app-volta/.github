# .github

Este repositório centraliza os arquivos de configuração e padronização utilizados pela organização.

## Objetivo

Manter uma estrutura única para apoiar o desenvolvimento dos projetos da organização, promovendo consistência nos processos e nas contribuições.

## Conteúdo

Este repositório pode conter:

* Templates de Issues
* Template de Pull Request
* Arquivos de configuração do GitHub
* Documentação da organização
* Fluxos de trabalho (GitHub Actions)
* Arquivos de suporte para os repositórios da organização

## Fluxo de Contribuição

1. Crie uma branch a partir da `develop`.
2. Realize as alterações necessárias.
3. Abra uma Pull Request para `develop`.
4. Após aprovação, as alterações poderão ser promovidas para `main`.

## Convenções

* Utilize mensagens de commit padronizadas (Conventional Commits).
* Mantenha os templates atualizados.
* Sempre abra uma Pull Request para integrar alterações.
